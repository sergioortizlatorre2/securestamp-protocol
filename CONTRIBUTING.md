# Contributing

Protocol issues, ADR proposals, and pull requests are welcome.

## Contribution Attribution

Public technical collaboration on this project is attributed as:

**Ivan**

This is a public/fictional name used to credit technical collaboration — it
does not refer to a human employee, founder, engineer, or legal
representative of SecureStamp.

- Do not add public references to Claude, Claude Code, Anthropic Claude, or
  other model-specific AI assistant names in documentation, credits,
  generated-by notes, commit trailers, or release material for this
  repository.
- Do not add `Co-authored-by: Claude ...` (or similar) trailers to commits.
- Where technical collaboration needs public attribution, use sober phrasing
  such as "Technical collaboration: Ivan" — not a claim that Ivan is a
  person, employee, or company representative.
- Historical commits are not rewritten; this policy governs current file
  content and future commits/contributions.
