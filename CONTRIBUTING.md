# Contributing

Protocol issues, ADR proposals, and pull requests are welcome.

## What belongs here

This repository is the public, technical home of the SecureStamp protocol: specifications,
ADRs, whitepapers and developer guides for MCP Guard, agents, harnesses and the published npm
packages. Contributions should stay technical and verifiable.

- Describe behaviour that can be checked against a published package, a public endpoint or
  the specification. Mark anything unreleased as such.
- Do not add commercial terms, customer names, business metrics, internal infrastructure
  identifiers or non-public endpoints.
- Report vulnerabilities privately to **security@securestamp.org**, not in a public issue.

## Contribution attribution

Public technical collaboration on this project is attributed as:

**Ivan**

This is a public, fictional name used to credit technical collaboration. It does not refer to
a human employee, founder, engineer or legal representative of SecureStamp.

- Do not name vendors, products or tools as authors, co-authors or collaborators in
  documentation, credits, generated-by notes, commit trailers or release material.
- Do not add `Co-authored-by:` trailers that name a tool or a vendor.
- Where technical collaboration needs public attribution, use sober phrasing such as
  "Technical collaboration: Ivan" — not a claim that Ivan is a person, employee or company
  representative. Examples in documentation use fictional people such as Juan or Eva.
- Historical commits are not rewritten; this policy governs current file content and future
  commits and contributions.
